# PARKING — web app

Інтерактивна версія застосунку з кейсу PARKING (UI/UX, 2026, Uliana Hontar).
Працює в браузері на телефоні й комп'ютері, на iPhone/Android можна «Додати на головний екран».

## Як викласти на Vercel

**Варіант 1 — без коду (найпростіший)**
1. Зайди на vercel.com → New Project.
2. Перетягни цю папку (`parking-app-vercel`) у вікно або вибери «Deploy» з папки.
3. Framework Preset: **Other**. Build Command і Output Directory залиш порожніми.
4. Deploy — за хвилину отримаєш посилання на кшталт `parking-xxx.vercel.app`.

**Варіант 2 — через GitHub**
1. Створи репозиторій і завантаж туди файли з цієї папки.
2. На Vercel: New Project → Import з GitHub → Framework: Other → Deploy.
3. Кожен новий push автоматично оновлюватиме сайт.

## Що всередині
- `index.html` — увесь застосунок (HTML + CSS + JS, без збірки).
- `manifest.webmanifest`, `icon*.png`, `icon.svg` — щоб його можна було встановити як застосунок.
- `vercel.json` — гарні URL без `.html`.

## Демо-примітки
- Оплата, коди підтвердження й сповіщення — демонстраційні, реальні гроші не списуються.
- Дані (авто, картки, історія) зберігаються лише в браузері відвідувача.
- Profile → Settings → Demo: прискорення часу, щоб швидко побачити попередження і завершення паркування.
- Profile → «Reset demo data» повертає початковий стан.
